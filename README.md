# Calculadora JS - Carla Hopp

Calculadora básica con JavaScript que pide nombre y dos números y muestra las 4 operaciones en consola.

**Link:** https://carlahopp.github.io/calculadora-js/

### Cómo funciona
1. Pide tu nombre
2. Pide 2 números con Number()
3. Abre la consola y te mostrará tu nombre, y las operaciones siguientes: (suma, resta, multiplicación y división).
